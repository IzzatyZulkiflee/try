Fail permainan:

- style.css
- game.js

Cara terbitkan menggunakan GitHub Pages:
1. Cipta repository baharu di GitHub.
2. Muat naik ketiga-tiga fail di atas ke root repository (jangan letakkan dalam subfolder).
3. Buka Settings > Pages.
4. Di bahagian Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder / (root), kemudian Save.
6. Tunggu GitHub Pages menerbitkan laman. Pautan game akan dipaparkan pada halaman Settings > Pages.
7. Tampal pautan itu dalam Google Classroom.

Semua fail diperlukan dan mesti kekal bersama. Game menggunakan HTML, CSS dan JavaScript biasa serta tidak memerlukan backend.
